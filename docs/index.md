Busy Tag is a status display with a 240 × 280 colour screen and an RGB LED bar. You manage it
from the **Busy Tag app** on Windows, macOS, Android and iOS.

## New to Busy Tag?

1. [Install the app](/getting-started/install) on your computer or phone.
2. [Connect your Busy Tag](/getting-started/connect) over USB or set it up on Wi-Fi.
3. [Take the tour](/getting-started/using-the-app): designs, LED colours, focus sessions and
   integrations.

Something not working? See [Troubleshooting & FAQ](/troubleshooting).

## Plugin user guides

Each built-in integration has a guide. It explains how to add and configure it, what it shows on
your Busy Tag, and how to fix common problems.

[Browse the plugin guides →](/plugins)
