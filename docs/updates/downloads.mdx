Installers of every released version of the Busy Tag app for Windows and macOS. To get the
current version, use the stores or [busytag.com/software](https://www.busytag.com/software)
([Install the app](/getting-started/install)); use this archive to go back to an earlier
version.

| File | What it is |
|:--|:--|
| **Setup (.exe)** | Windows setup program. |
| **App package (.msix)** | Windows app package. Double-click it to install. |
| **Installer (.pkg)** | macOS installer package. |

Use the **Arm64** build on Windows PCs with an Arm processor (for example Snapdragon) and **x64**
on all others. Versions before 1.6.4 have only an x64 build.

:::note
Older versions may lack support for newer firmware and Busy Tag 2 features. Android and iOS
versions are only available from Google Play and the App Store.
:::
